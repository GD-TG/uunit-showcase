# АИС «Витрина ИТ-проектов» (УУНиТ)

Автоматизированная информационная система для организации прямого взаимодействия обучающихся ФГБОУ ВО «Уфимский университет науки и технологий» (УУНиТ) с компаниями реального сектора экономики и индустриальными ИТ-лидерами (Яндекс, Сбер, Positive Technologies).

---

## 🚀 Стек технологий

* **Backend:** Python 3.12, FastAPI, Uvicorn, Pydantic v2.
* **База данных:** PostgreSQL 16 (с поддержкой asyncpg и SQLite fallback), SQLAlchemy 2.0 Async, Alembic.
* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons, Recharts.
* **Дизайн-система:** эстетика уровня **Fable / Linear** (глубокая палитра, glassmorphism, неоновые акценты, micro-interactions, адаптивность 375px–1920px).
* **Экспорт отчетов:** Excel (.xlsx через OpenPyXL), CSV, PDF (ReportLab).
* **Контейнеризация:** Docker & Docker Compose.

---

## ⚡ Быстрый запуск

### Вариант 1: Запуск одной командой (Docker Compose)

```bash
docker compose up --build
```
* Веб-интерфейс: `http://localhost:8000/`
* Swagger/OpenAPI документация: `http://localhost:8000/docs`

---

### Вариант 2: Локальный запуск (Разработка)

#### 1. Backend:
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
pip install -r requirements.txt greenlet

# Наполнение демонстрационными данными УУНиТ:
python seed_demo_data.py

# Запуск сервера:
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

#### 2. Frontend:
```bash
cd frontend
npm install
npm run dev
# Открыть http://localhost:5173
```

## 📋 Покрытие 19 сквозных приемочных сценариев (п. 43–62 ТЗ)

1. **Регистрация компании** (п. 43) — профиль, реквизиты, направления, контакты.
2. **Модерация компании** (п. 44) — проверка и подтверждение сотрудником УУНиТ во вкладке «Модерация».
3. **Создание кейса** (п. 45) — выбор из 4 категорий (конкурсный, оплачиваемый, образовательный, стажировка), призовой фонд, компетенции, NDA.
4. **Публикация кейса** (п. 46) — появление на витрине после одобрения.
5. **Поиск кейса студентом** (п. 47) — мультифильтры (стек, курс, формат, оплата, направления).
6. **Подача заявки** (п. 48) — отправка мотивационного письма, ссылок на GitHub и портфолио.
7. **Принятие заявки компанией** (п. 49) — отбор кандидатов в личном кабинете.
8. **Формирование команды** (п. 50) — распределение ролей (Team Lead, Backend, Frontend, Data Scientist, QA и др.).
9. **Выполнение проекта** (п. 51) — трекинг статусов в рабочем пространстве.
10. **Загрузка промежуточного результата** (п. 52) — сдача контрольных точек и комментарии наставника.
11. **Загрузка итогового решения** (п. 53) — репозиторий GitHub, ссылка на демо-сервис, презентация.
12. **Оценка компанией** (п. 54) — оценка строго по 10 регламентированным критериям ТЗ (1–10) + отзыв + итоговый балл (0–100).
13. **Определение победителя** (п. 55) — 1, 2, 3 места и специальные номинации.
14. **Отображение проекта в портфолио** (п. 56) — официальная плашка «Проект подтверждён компанией».
15. **Создание студентом собственного проекта** (п. 57) — публикация pet-проектов с 6 статусными бейджами («Ищу команду», «Открыт к работе»).
16. **Просмотр студенческого проекта компанией** (п. 58) — изучение кода и демо.
17. **Поиск студентов по компетенциям** (п. 59) — хедхантинг-панель для работодателей.
18. **Формирование аналитического отчёта** (п. 60) — интерактивные графики Recharts.
19. **Экспорт данных** (п. 61) — мгновенная выгрузка отчетов в Excel (.xlsx), CSV и PDF.
20. **Работа системы уведомлений** (п. 62) — пуши о смене статусов, ревью и заявках.
